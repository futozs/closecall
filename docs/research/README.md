# Research

Dated research notes from 2026-11-16, written under the working title „Bezártam?” before the project
was named Close Call. Versions, prices and maintenance status in them age quickly; re-check anything
before quoting it. Decisions taken from these notes are recorded in [../decisions/](../decisions/README.md),
and those win where the two disagree (for example, the default unsaved policy is now `save_then_close`).
