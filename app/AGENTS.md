# app

`app/src-tauri` is the Tauri shell (tray, settings window, IPC commands, hotkey, autostart, single
instance, CLI arguments `panic`, `status`, `explain`, `diag`). `app/src` is the React 19 + Vite UI.

## Rules

- Keep `src-tauri` thin: commands are the table in `crates/core/src/ipc.rs`, with those exact names
  and types. Logic belongs in `engine` or `core`.
- `app/src/bindings/` is generated by ts-rs. Never edit it; run `cargo test -p closecall-core export_bindings`.
- `app/src/ipc.ts` is the only module that calls `invoke` or `listen`.
- No `fetch`, `XMLHttpRequest`, `WebSocket`, `EventSource` or `navigator.sendBeacon`. No remote
  fonts, images or scripts; everything is bundled.
- The CSP in `src-tauri/tauri.conf.json` and `src-tauri/capabilities/` are security boundaries. Do not
  widen them without the owner. No `updater`, `http`, `websocket`, `upload` or `shell` plugin.
- Autostart uses `MacosLauncher::LaunchAgent`, never the AppleScript launcher (it adds an Automation prompt).
- Every string comes from `locales/{en,hu}`; Rust sends keys and parameters. Plurals go through
  `Intl.PluralRules`. Hungarian: „…” quotes, ő/ű, singular noun after a numeral.
- Notifications show counts only, never titles, URLs or paths. Our own windows hide when a share signal fires.

## Verify

```sh
bun run check          # tsc --noEmit
bun x biome check .
bun x vitest run
bun x playwright test  # web build with @tauri-apps/api/mocks
```

Look at UI changes in both languages, at the default size and at the minimum window size (720×520).
