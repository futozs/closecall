# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in issues, pull requests, discussions and any other project space.

To report unacceptable behaviour, contact the maintainer, [futozs](https://github.com/futozs), through
GitHub. If it should not be public, open a private report through
[the repository's Security tab](https://github.com/futozs/closecall/security/advisories/new) and say
in the title that it is a conduct report. Reports are handled privately, and the enforcement
guidelines in the Covenant apply.
